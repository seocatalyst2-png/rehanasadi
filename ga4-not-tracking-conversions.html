Frequently Asked Questions

Why aren’t my conversions showing in GA4? +
Conversions or key events may not appear in GA4 for several reasons: the event tag is not firing in Google Tag Manager, the event name does not match the registered trigger, the event has not been marked as a key event in GA4 admin, data processing latency (standard GA4 reports take 24–48 hours to fully populate), Google Signals thresholds, or consent management blocks before user acceptance.
What is the difference between a GA4 event and a key event? +
In GA4, every interaction is tracked as an event (e.g., page_view, click, scroll). In early 2024, Google rebranded conversions within GA4 to "key events" to distinguish them from Google Ads conversions. Marking an event as a key event flags it as important for attribution and reporting without altering how the underlying event data is collected.
Do I still need Google Tag Manager? +
Google Tag Manager (GTM) is not strictly mandatory if you use direct gtag.js code or dedicated CMS native pixels, but it is strongly recommended. GTM provides centralized tag management, precise trigger control, custom data layer variables, and live preview debugging without requiring direct theme code edits for every tracking change.
Can you fix an existing GA4 setup? +
Yes. Most engagements involve auditing and fixing broken or incomplete existing implementations—such as missing lead submissions, zero-value ecommerce purchases, incorrect event parameters, duplicate transactions, or broken cross-domain tracking.
Can you set up new events or key events? +
Yes. I configure both standard recommended events (such as generate_lead, view_item, add_to_cart, begin_checkout, and purchase) and custom business events with tailored parameters, registering them properly as key events in GA4.
Can you fix purchase and revenue tracking problems? +
Yes. Common purchase tracking issues include missing order values, zero revenue, currency discrepancies, and missing transaction IDs. I inspect your data layer and server payloads to ensure every purchase event transmits clean, standardized ecommerce item arrays and monetary values.
Why are my GA4 purchase numbers duplicated? +
Duplicate purchases usually happen when customers reload their order confirmation page, reopen old order confirmation emails, or when multiple tracking mechanisms (such as a CMS native app and GTM) fire simultaneously. I implement unique transaction ID deduplication and robust firing triggers to eliminate duplicate counting.
Will this recover my past data? +
No. If events were never sent to or recorded by GA4, Google Analytics cannot retroactively reconstruct or recover that missing historical event data. The fix ensures that moving forward, all events and key conversions are recorded accurately and reliably. If you have separate historical records in your CRM or ecommerce store database, those can be used externally for business reconciliation.
Will this work with Google Ads? +
Yes. GA4 key events can be imported into Google Ads as conversion actions. However, direct Google Ads conversion tracking via the Google tag or GTM is often preferable for smart bidding due to real-time attribution and enhanced conversions support. I review how your GA4 events align with your Google Ads conversion actions to prevent double-counting or attribution gaps.
Does this fix Meta tracking too? +
Google Analytics 4 and Meta (Facebook) are completely separate tracking platforms with different event structures, APIs, and attribution logic. A GA4 repair addresses Google Analytics. If you also need Meta Conversions API or Meta Pixel setup, that is handled as a dedicated Meta CAPI setup.
Do you work with Shopify? +
Yes. Shopify has unique tracking considerations, especially around checkout extensibility, customer events web pixels, and post-purchase thank-you pages. I fix both standard and Shopify Plus ecommerce tracking implementations. Learn more on my dedicated Shopify GA4 tracking page.
How do you test whether GA4 is working correctly? +
Validation is conducted using GA4 DebugView, Google Tag Manager Preview mode, Google Tag Assistant, and browser network request analysis. Each event is triggered and verified in real time to ensure parameter integrity and trigger accuracy before deploying tags live.
How long does it take to fix? +
The turnaround time depends on the complexity of your site, the number of missing or broken events, your CMS platform, and your consent management configuration. After an initial technical inspection, I provide a clear estimated timeline tailored to your scope.
Is there a fixed price? +
Because every tracking setup varies—from single lead form repairs to complex multi-domain ecommerce funnels—pricing is customized to the specific technical requirements of your site. Contact me via WhatsApp for a direct, upfront quote.
