01

Slageronline.nl — Dutch e-commerce butcher

Meta CAPI E-commerce / NL sGTM

The problem

Client was running Meta Ads essentially blind. Browser-only pixel was blocked by iOS tracking prevention and Dutch ad blockers. Roughly 35% of purchase events were never reaching Meta. ROAS calculations were built on fiction, and campaign optimization was targeting the wrong audience signals.

What I built

01Deployed GTM server container via Stape.io with custom subdomain for first-party cookie persistence
02Configured Meta Conversions API (CAPI) with server-side event deduplication against the browser pixel
03Mapped full e-commerce event schema: ViewContent to AddToCart to InitiateCheckout to Purchase with correct value and currency parameters
04Set up GA4 with enhanced e-commerce and Looker Studio dashboard for weekly reporting
05Managed Meta Ads campaigns (~EUR100/day) post-implementation with improved audience signals feeding optimization

NordSleeps — DTC sleep brand, Netherlands

Server-side DTC / NL GA4

The problem

GA4 was installed client-side with no server container. Cookie lifetime was capped at 7 days by Safari ITP, making returning customer attribution difficult. The existing GTM container had 40+ orphaned tags from a previous agency, causing duplicate events and inflated session counts.

What I built

01Full GTM container audit, removed 40+ dead tags, rebuilt with clear naming conventions
02Deployed sGTM via Stape.io and set first-party cookies server-side to bypass ITP (7-day to 400-day persistence)
03Rebuilt GA4 e-commerce implementation with correct item-scoped parameters for Shopify checkout flow
04Routed Meta Pixel through server container to reduce client-side load and improve data quality
